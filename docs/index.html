04

Questions, answered

Does KenjaGrid upload my workbooks anywhere?

No. Creating, editing, calculating, formatting, charting and exporting all run locally on your machine. The app initiates no network traffic of its own — the only traffic ever sent is an AI-chat request that you triggered, delivered straight to the endpoint you configured. And because KenjaGrid is open source, you can verify all of this in the public code.

Can the AI assistant edit my workbook?

Not by default. The assistant answers questions about the active workbook through inspection tools — a workbook or sheet summary, cell reads, text search — and read-only is the default. It can only modify anything after you explicitly switch to one of the edit modes. The conversation lives in memory only, and in the browser build the AI assistant is unavailable.

Which AI models can I use?

Any OpenAI-compatible endpoint you configure yourself: OpenAI, DeepSeek, Qwen, or a local server such as Ollama or LM Studio. Your API key is stored on your machine and sent only to the base URL you configured, only when you send a message. The app is fully functional without any AI.

Can KenjaGrid open my Excel files?

Yes. XLSX is the native format: styles, themes, formulas (including dynamic arrays), tables, conditional formats, validation, comments, hyperlinks, charts, pictures, sparklines, pivot tables and print settings all round-trip. It also reads and writes CSV and TSV, opens legacy 97-2003 .xls workbooks with their values, formulas and number formats, and imports worksheet data from XLSB and ODS files.

Which platforms does KenjaGrid run on?

Native macOS (Apple silicon and Intel, signed and notarized), Windows (x64, arm64 and x86, code-signed), Linux (AppImage, Flatpak, deb, rpm and tarball on x86_64 and ARM64), FreeBSD, and the web via WebAssembly.

Is KenjaGrid really free?

Yes — free and open source under the MIT or Apache-2.0 licence, your choice. No subscription, no licence server, no telemetry. It is in active development (alpha): the core spreadsheet workflow works end to end, and compatibility depth keeps growing in the open, with a public roadmap.
